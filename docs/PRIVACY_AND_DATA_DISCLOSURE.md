# AI Tutor 隐私与数据披露

更新日期：2026-08-02

本文说明当前代码实际会保存或传输什么。它是工程披露，不是外部法律意见；公开部署前仍需按比赛规则、服务条款和适用地区完成独立复核。

## 不联网也能完成的路径

盒模型、Flex 和定位的确定性课程、实验、比较、解释、迁移和回放不需要登录、Realtime 或麦克风。画布快照与尚未同步的 Learning Proof 记录保存在当前浏览器的 `localStorage`。清除站点数据会删除这些设备本地记录。

上传入口只接受受大小和类型约束的静态 HTML/CSS。应用会移除脚本并在 sandbox iframe 中运行；不会执行上传文件中的 JavaScript。

## 设备标识与权威课程记录

服务端会设置一个最长 30 天的 `HttpOnly`、`SameSite=Strict` owner cookie，用于把 Realtime 与 Learning Proof API 限定到当前浏览器所有者。它不是广告或跨站跟踪 cookie。

配置 `DATABASE_URL` 后，PostgreSQL 会保存 owner-bound 课程会话、追加事件、确定性快照与回放状态。事件可包含课程选择、预测、实验块与 revision ID、解释/迁移答案和机器评价证据；不保存原始麦克风音频。当前公开产品尚没有完整的自助式“删除全部 PostgreSQL 记录”界面，部署者必须按发布手册执行保留与删除策略。

## 文字与语音 Tutor

只有用户主动开始文字或语音会话后，应用才会启动 Realtime 路径。文字问题、语音转录、Tutor 输出以及允许的结构化画布工具参数/结果可能经本机 Codex app-server 发送给配置的 OpenAI 服务。确定性演示不会启动这条路径。

语音会话会先完成能力检查，再由浏览器显示麦克风权限请求。拒绝麦克风后仍可使用文字和确定性课程。自动化验收只使用合成假麦克风并静音，从不访问物理麦克风。

语音设置会把用户明确选择的说话方式、浏览器提供的麦克风 `deviceId`、输出音量、语速和字幕偏好保存在当前浏览器的 `localStorage`，不上传这些偏好。新设备默认不选择说话方式，必须先选择“按住说话”或“持续聆听”才能开始；刷新不会自动启动麦克风。用户可在“语音设置”中选择“恢复默认并忘记设备”，也可通过清除站点数据删除这些本机偏好。关闭讲解声音时，应用强制保留字幕。

用户勾选保存学习记录时，含内容的本机 NDJSON 日志最长保留 7 天；未勾选时只保留不含对话或页面内容的最小运行记录，最长 24 小时。日志写入前会清理原始音频、SDP、OAuth、Cookie、Token、API Key 和已知 PII 模式，并提供当前会话导出与删除。

## 第三方网络行为

应用代码没有接入自有广告或行为分析 SDK。固定版本 tldraw 3.15.5 使用必须保留的可见水印免费许可路径。在公开、非 localhost 的 HTTPS origin 上，未授权 SDK 可能从 tldraw 默认 CDN 请求水印跟踪 SVG；本机 HTTP/localhost 验收不会发起该请求。公开部署必须在隐私说明和 CSP/网络审查中保留这项披露。
