# AI Tutor 对外主张边界

更新日期：2026-08-02

## 机器证据支持的说法

- 产品提供盒模型、Flex 和定位三条确定性 Predict–Observe–Explain–Transfer 课程，并能回放追加式 Learning Proof。
- 静态 HTML/CSS 在 sandbox iframe 中运行，上传 JavaScript 不执行。
- 文字与确定性路径不调用麦克风；隔离语音验收使用假麦克风并静音。
- PostgreSQL 权威事件、快照与回放使用 owner、序号、哈希、幂等和确定性 reducer 校验。
- 关键因果断言必须取得当前回合的 target、前后值、规则与 revision 事实包；证据不足时运行时拒绝断言。
- 固定版本 tldraw 3.15.5 的可见水印保留，许可证副本、生产依赖清单和 SBOM 已入库。
- 本地 loopback Docker Compose 可启动 Web 与 PostgreSQL，健康检查执行真实数据库查询。

每条说法必须链接到当前测试输出或 `evidence/` 文件；测试失败后不得继续沿用旧结论。

## 只能有限表述的说法

- 单次迁移通过只能写“本次课内达成”，不能写“已经掌握”。
- 自动 axe、键盘、forced-colors、reduced-motion 和触摸模拟通过，不等于真人读屏或真实设备全面通过。
- 假麦克风 Live 通过证明协议和机器路径，不证明真人听感、所有网络或所有账号长期可用。
- SBOM、许可证副本和水印测试是工程合规证据，不是外部法律意见。
- 当前 20 runtime / 50 block 短时性能门禁只描述所记录机器、版本和负载；没有合格的当前源码 30 分钟 soak。用户已取消重跑，目标 083 保持未验证。
- 当前回合 assertion-evidence receipt 没有作为独立字段持久化到数据库，不能声称每条 Realtime 因果话术都可在历史回放中逐字追溯。

## 当前绝不能声称

- “经真人证明能提高学习效果”
- “12 名学生全部完成”或任何尚未发生的研究结果
- “已经掌握 CSS”或用单题替代延迟保持
- “符合所有比赛规则”——具体官方比赛尚未冻结
- “已经完成法律/隐私/商标审查”
- “已购买 tldraw 或其他商业许可证”
- “已公开部署”或“所有网络均可用”
- “当前候选已通过 30 分钟稳定性浸泡”
- “机器测试等同于真人验收、专家审核或独立 go/no-go”

## 外部证据到位后的更新规则

官方规则、真人数据、专家意见、设备验收和独立审查必须保存原始来源、时间、版本、失败样本和负责人。新增证据只能追加或产生新版本，不能静默改写旧机器记录。
