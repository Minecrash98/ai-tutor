# AI Tutor 比赛候选范围

## 唯一首要用户

第一次系统学习 CSS 盒模型、Flex 或定位的中文学习者。学习者会使用浏览器并能输入一条 CSS 声明，但不要求会使用开发者工具，也不要求登录、上传文件或授权麦克风。

## 唯一首要任务

在没有说明员代做的情况下，完成一节“先判断、亲手操作、解释原因、在结构不同的新页面迁移”的 CSS 可视化小课，并得到一条可回到真实页面、版本和学生事件的课内证据。

首个舞台切片固定为盒模型：学生判断 padding 变化，拖动控制器，解释因果，再在新页面亲手写一条 CSS。Flex、定位和“我的页面”只复用同一学习闭环，不增加另一套产品叙事。

## 首页入口边界

- 推荐入口：一分钟盒模型课。
- 接续入口：Flex 或定位完整小课。
- 真实任务入口：载入自己的静态 HTML/CSS，并只在存在稳定源码事实时生成小课。
- 可选入口：文字或语音学习搭档；不可用时明确回到确定性演示。
- 高级画布块与内部工程细节默认折叠，不作为初学者首要入口。
