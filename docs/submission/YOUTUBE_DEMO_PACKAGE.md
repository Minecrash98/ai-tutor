# YouTube demo package

## Title

AI Tutor: Learn CSS Global Color Variables in 5 Minutes

## Description

AI Tutor is a visual learning canvas for CSS beginners. This real browser demo
imports an English HTML/CSS exercise, reveals the global color tokens in
:root, changes one shared brand value, expands it into a mint theme, safely
previews the result, saves an immutable version, and compares both outcomes.

The product is designed around Predict–Observe–Explain–Transfer rather than
answer generation alone. Tutor claims can be grounded in page facts, and
lesson, tutor, tool, and canvas events can be replayed as Learning Proof.

Honest scope: this video demonstrates implemented machine-validated behavior.
It is not human learning-outcome evidence. The current product shell is
localized in Chinese; the imported lesson, video captions, narration, and
submission materials are English. Optional Realtime features depend on an
authenticated local Codex app-server; deterministic lessons do not.
