## Summary

AI Tutor is a visual learning canvas for CSS beginners who can read an
explanation but struggle to connect code with what changes on screen. It
imports real HTML and CSS, guides a Predict–Observe–Explain–Transfer loop,
previews edits safely, saves immutable versions, and turns lesson, tutor, tool,
and canvas events into replayable learning evidence. It matters because AI
teaching stays grounded in the learner's actual page instead of giving generic
answers.
